## Related work

Industrial fault diagnosis has long been benchmarked on measured data: LiU-ICE provides engine test-bench data for fault detection and isolation, and HSU TwinFlow generates labelled fault scenarios from a production-system digital twin. Recent work separates causes explicitly. telemetry-triage attributes streaming anomalies to process change, instrument fault or data-path corruption and allows an undetermined answer, and TelemetrySuffBench scores abstention when evidence is insufficient. Agent-style evaluations include FaultArena, a tool-driven maintenance-diagnosis environment, and AssetOpsBench, a multi-agent suite for asset operations; FactoryBench poses question answering over robot telemetry. CPBench contributes a permissioned HMI/MES/PLC interaction protocol for a stopped production-line station, with real-fault and sensor-false-alarm branches and a rule-based safety audit. It does not yet score insufficient-evidence cases.
